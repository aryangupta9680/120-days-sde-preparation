## DSA

Solved **Single Number (LeetCode 136)** using four different approaches:

* **Brute Force:** Count how many times each element appears. — O(n²) time, O(1) space
* **Sorting:** Sort the array and check elements in pairs. — O(n log n) time, O(1) space
* **Hashing:** Use `unordered_map` to store the frequency of each element. — O(n) time, O(n) space
* **XOR:** XOR all elements. The duplicate numbers cancel out, leaving the single number. — O(n) time, O(1) space
