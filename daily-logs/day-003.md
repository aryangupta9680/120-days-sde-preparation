## DSA

Solved **Majority Element (LeetCode 169)** using four different approaches:

* **Brute Force:** Used nested loops to count the frequency of each element — **O(n²)** time and **O(1)** space.
* **Sorting:** Sorted the array and selected the middle element — **O(n log n)** time and **O(1)** space.
* **Hashing:** Used an `unordered_map` to store the frequency of each element — **O(n)** time and **O(n)** space.
* **Boyer-Moore Voting Algorithm:** Tracked a candidate and its count using the cancellation approach — **O(n)** time and **O(1)** space.
